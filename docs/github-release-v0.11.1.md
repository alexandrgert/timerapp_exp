# GitHub Release v0.11.1 — черновик описания

Экспериментальный релиз **TaskTimer Experiment** ([timerapp_exp](https://github.com/alexandrgert/timerapp_exp)).

Сравнение с **[v0.11.0](https://github.com/alexandrgert/timerapp_exp/releases/tag/v0.11.0)**.

## Что нового

- Проверка обновлений **только** по `alexandrgert/timerapp_exp` (поле смены репозитория убрано)
- Полная матрица Linux-пакетов как в 0.11.0

## Установка (Linux amd64)

```bash
wget https://github.com/alexandrgert/timerapp_exp/releases/download/v0.11.1/timerapp-exp-0.11.1-amd64.deb
sudo dpkg -i timerapp-exp-0.11.1-amd64.deb
sudo apt-get install -f
timerapp-exp
```
