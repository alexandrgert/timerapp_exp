## Что нового

### Результат при завершении

- При **Завершить** обязателен непустой **результат**; «Отмена» закрывает диалог без требования.
- Результат хранится в задаче (`result` в `data.json`), показывается в строке / карточке и участвует в отчёте дня.
- В **редактировании** завершённой задачи результат нельзя очистить до пустого.

### Возобновление и история сессий

- При **Возобновить** можно указать **причину** — она пишется в `comment` новой сессии.
- Кнопка **История** доступна всегда (не только для завершённых): сессии, длительность, комментарий, отметка передачи в Bitrix («передано»).

### Отчёт дня

- Кнопка **Отчёт дня**: краткий markdown (название, время за день, результат при наличии).
- Опционально **расширенный** отчёт (с подтверждением): плюс описание задачи и таблица сессий за день.
- Копирование в буфер обмена.

### Приоритет перед стартом

- Если на сегодня приоритет ещё **не задан**, перед стартом / возобновлением запрашивается уровень 1–4.
- На desktop после назначения приоритета (одиночно и группой) **снимаются галочки** выделения.
- На Android — **selection mode** (long-press): массовое назначение приоритета с очисткой только затронутых ID.

### Android: паритет с desktop 0.6.x / 0.7.0

- Модели и WebDAV merge сохраняют `result`, `comment`, `daily_priorities`, `bitrix_record_id`.
- UI: завершение с результатом, возобновление с причиной, история, отчёт дня, фильтр приоритетов, запрос приоритета перед стартом/resume.
- Selection mode для batch-приоритета без постоянных чекбоксов в обычном списке.

### Данные и схема

- Поле **`result`** у задачи (см. [data-schema.md](data-schema.md)).
- Merge на desktop и Android не теряет результат и приоритеты при синке.

## Сборки

| Платформа | Файл |
|-----------|------|
| Linux amd64 | `timerapp-exp-0.7.0-amd64.deb` |
| Android 10+ | `timerapp-exp-0.7.0-android.apk` |
| Windows | `timerapp-exp-0.7.0-win64.exe` (или zip из CI) |
| macOS | zip из CI |

**Linux:**

```bash
wget https://github.com/alexandrgert/timerapp_exp/releases/download/v0.7.0/timerapp-exp-0.7.0-amd64.deb
sudo dpkg -i timerapp-exp-0.7.0-amd64.deb
sudo apt-get install -f
timerapp-exp
```

**Android:** установите APK поверх текущей сборки Experiment (та же подпись) — данные и WebDAV сохранятся.
