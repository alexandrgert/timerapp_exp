# TaskTimer Experiment 0.11.7

Полный выпуск для Linux, Windows, macOS и Android. Общая версия — **0.11.7**;
Android `versionCode` — **1107**. Изменения относительно полного релиза 0.11.5
включают доработки, ранее доступные в отдельных preview-сборках.

## Desktop

- После удаления выбранной задачи очищается её выделение. Сообщение
  «Скрыто выбрано» больше не учитывает удалённую задачу. Существующие задачи,
  скрытые фильтром, остаются выбранными; массовое изменение приоритета исключает
  несуществующие записи.
- Linux собирается на Ubuntu 20.04 с CPython 3.12.14 и PySide6 6.9.3.
  Проверка всех ELF-файлов ограничивает требуемую glibc версией 2.31.
  Это исправляет несовместимость прежнего DEB 0.11.5 с Ubuntu 20.04/22.04.
- В DEB добавлены журнал запуска и диалог при аварийном завершении.
  Журналы: `${XDG_STATE_HOME:-$HOME/.local/state}/timerapp-exp/`.
- Исправлена база часовых поясов среды Linux-сборки.

Правила выбора приоритета при создании задачи в этом выпуске не менялись.

## Android

- Добавлены ручное редактирование сессий и подтверждение удаления;
  сохраняются черновики редактирования.
- Добавлены управление концентрацией и офлайн-диктовка на русском языке
  через sherpa-onnx / Zipformer RU INT8.
- Модель речи загружается отдельно: архив 60 239 942 байта,
  после распаковки — 74 004 174 байта. Для первой загрузки нужен интернет;
  после установки распознавание работает локально.
- Улучшены распаковка модели, индикация прогресса и сообщения об ошибках.
  Проверенный архив сохраняется для повторной установки без скачивания.

Release APK имеет application ID `com.timerapp.exp` и подписывается постоянным
ключом выпуска из GitHub Secrets. Отдельный Preview (`com.timerapp.exp.preview`)
остаётся отдельным приложением; его данные автоматически не переносятся.
Обновление поверх существующего Experiment возможно при совпадении подписи.

## Установка и пакеты

- **Linux x86_64:** DEB, RPM, TAR.XZ, TGZ, AppImage, Flatpak, Snap,
  Gentoo ebuild/overlay, PiSi, PET, PUP и LZM.
  Gentoo, PiSi, PET, PUP и LZM остаются экспериментальными форматами.
- **Windows x64:** EXE.
- **macOS Apple Silicon:** ZIP с приложением, архитектура arm64.
- **Android 10+:** APK.

Для Ubuntu **20.04 и новее**, amd64:

```bash
sudo apt install ./timerapp-exp-0.11.7-amd64.deb
```

Python отдельно устанавливать не требуется. В `SHA256SUMS` опубликованы
контрольные суммы всех 16 пакетов; `build-info.txt` содержит точный коммит
и ссылку на сборку GitHub Actions.

## Проверки и ограничения

Публикация полного выпуска разрешается workflow только после прохождения
desktop-тестов (включая регрессии выделения), Android unit-тестов, проверки
подписи и версии APK, сборки всех форматов и установки/запуска DEB на Ubuntu
20.04, 22.04, 24.04 и 26.04 под Xvfb/X11 от обычного пользователя.

Эти проверки не заменяют ручную проверку Wayland, трея, установки остальных
форматов и работы на физических Windows/macOS/Android-устройствах.
Windows и macOS пакеты не имеют подписи издателя/Apple notarization.

Протокол WebDAV не менялся: известное ограничение прежнего merge может
восстанавливать удалённые записи или старые поля сессий при синхронизации.
Исправление локального выделения задач не является исправлением WebDAV.

Результат ClamAV предыдущего DEB 0.11.5 не относится к этим новым пакетам.
Причина прежней блокировки ZIP в Chrome не установлена; контрольная сумма
позволяет проверить целостность, но не заменяет антивирусную проверку.
