# Инструкция пользователя TaskTimer PWA

[Скачать HTML-инструкцию](https://github.com/alexandrgert/timerapp_exp/raw/refs/heads/main/docs/user-guide/TaskTimer-instruction.html). Сохраните файл и откройте в браузере: все изображения встроены, сеть для чтения не нужна. Просмотр HTML через GitHub показывает исходный код, а не страницу приложения.

Инструкция соответствует опубликованной PWA на 9 октября 2026 года. Все скриншоты содержат демонстрационные данные.

## Поддержка актуальности

При изменении пользовательского поведения PWA обновлять затронутые разделы в `make-guide.py`, а при изменении интерфейса — соответствующие PNG в `screenshots/`. Использовать демонстрационные данные без паролей и персональных сведений. Указывать дату и версию, которым соответствует инструкция; не представлять невыпущенные функции как уже доступные.

Пересоздать HTML: `python3 docs/user-guide/make-guide.py` из корня репозитория. Проверить загрузку всех изображений, ссылки оглавления и соответствие описания опубликованным сценариям. Подготовку документации выполнять вместе с функциональными изменениями, публикацию пользовательской инструкции — согласованно с выпуском.

Основная копия для пользователей находится в `main/docs/user-guide/`. Исходники руководства также поддерживаются в ветке разработки PWA. Обновлять основную копию отдельным коммитом документации, не сливая туда всю ветку приложения и не запуская native-сборки.

GitHub Pages публикует эту HTML-копию по адресу `/timerapp_exp/guide/` из ветки публикации. Изменение только `main` не обновляет страницу: включайте актуальный документ в согласованный выпуск PWA.
