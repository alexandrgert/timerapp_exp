# TaskTimer Experiment 0.11.8

Полный выпуск для Linux, Windows, macOS и Android. Общая версия — **0.11.8**;
Android `versionCode` — **1108**. Изменения относительно 0.11.7.

## WebDAV: совместимый протокол v2

- Android, desktop и PWA используют общий протокол синхронизации с журналом
  изменений. Удаления сохраняются; одновременные изменения одного поля остаются
  доступными для явного выбора, а не теряются при выборе последней копии файла.
- Изменения времени сессий и комментариев синхронизируются вместе с задачами.
  Одновременные запуски таймеров требуют выбора активной сессии; история сохраняется.
- Запись на сервер использует ETag и условные запросы. При изменении серверной
  копии клиент повторно получает и объединяет данные. Сервер без сильного ETag
  сообщает об ошибке вместо небезопасной перезаписи.
- Новый ресурс — прежний путь плюс `.v2.json`, например `tasks.json.v2.json`.
  Старый файл не перезаписывается. Предусмотрены резервная копия и однократный
  импорт прежних данных; различающиеся значения могут потребовать разрешения
  конфликтов.

Для совместной синхронизации обновите Android и desktop до 0.11.8. Старые клиенты
продолжают работать с прежним файлом и не получают последующие изменения v2.
Перед переходом сохраните резервные копии на каждом устройстве. Проверка с вашим
WebDAV-сервером остаётся необходимой; для PWA сервер также должен разрешать CORS.

## PWA

В репозитории добавлено веб-приложение: задачи, таймер, история и редактирование
сессий, концентрация, локальное хранение, резервные копии, WebDAV v2 и русская
офлайн-диктовка через sherpa-onnx / Zipformer. Речевая модель загружается отдельно;
первичная загрузка требует сети. После установки модель обрабатывает звук локально.

Отдельная проверка PWA в GitHub Actions №36843505302 прошла: браузерные проверки,
Service Worker с офлайн-режимом и обновлением, а также реальное распознавание
контрольной русской записи в Chromium/WASM. Это не проверка микрофона телефона.
Постоянный сайт GitHub Pages ещё не опубликован; этот выпуск нативных пакетов
сам по себе не публикует PWA. Работа на физических телефонах и публичном HTTPS
адресе остаётся отдельным этапом проверки.

## Пакеты и установка

- **Linux x86_64:** DEB, RPM, TAR.XZ, TGZ, AppImage, Flatpak, Snap,
  Gentoo ebuild/overlay, PiSi, PET, PUP и LZM. Последние пять форматов
  остаются экспериментальными.
- **Windows x64:** EXE.
- **macOS Apple Silicon:** ZIP с приложением arm64.
- **Android 10+:** APK с application ID `com.timerapp.exp`.

Для Ubuntu 20.04 и новее, amd64:

```bash
sudo apt install ./timerapp-exp-0.11.8-amd64.deb
```

Python отдельно устанавливать не требуется. APK подписывается постоянным ключом
выпуска; обновление поверх установленного Experiment возможно при совпадении
подписи. Preview остаётся отдельным приложением без автоматического переноса данных.

## Проверки выпуска и ограничения

Workflow разрешает публикацию только после desktop-тестов, Android unit-тестов,
проверки версии и подписи APK, подготовки всех 16 пакетов и установки/запуска DEB
на Ubuntu 20.04, 22.04, 24.04 и 26.04. `SHA256SUMS` содержит суммы пакетов,
`build-info.txt` — точный коммит и ссылку на запуск GitHub Actions.

До завершения этого запуска его проверки не считаются пройденными. Ручная
проверка обновления данных, WebDAV между физическими устройствами, Wayland/трея
и установки остальных форматов не заменяется автоматическими тестами.
Windows и macOS пакеты не имеют подписи издателя/Apple notarization.
Антивирусная проверка новых пакетов отдельно не выполнялась; старые результаты
сканирования не относятся к этому выпуску.
