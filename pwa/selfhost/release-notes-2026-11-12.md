# TaskTimer PWA Self-host preview

Отдельный серверный вариант для одного владельца и нескольких устройств. Архив содержит исходники готового Node.js runtime, без npm-зависимостей для работы. Это предварительный выпуск; установку на целевой сервер ещё нужно проверить.

Включены актуальный интерфейс TaskTimer PWA, постоянная сортировка, счётчики, единый таймер концентрации, понятные конфликты и исправление запуска с сохранённым конфликтом. Запуск, пауза, продолжение и завершение таймера передаются между устройствами после успешного обмена. Конфликт другого поля не блокирует получение остановки. Автообмен — через 10 секунд после изменений и каждые 30 секунд в видимой PWA; немедленная доставка в фоне или без сети не гарантируется.

Собственный API `/api/sync`, SQLite и отдельные отзывные ключи устройств. GitHub-токен серверной версии не нужен. Документ до 20 МиБ, условная запись по ETag и причинная история. Схема SQLite прежняя; пользовательские базы и ключи в архив не входят.

Для установки: Node.js 24 LTS, отдельный домен с HTTPS, постоянный локальный каталог данных и reverse proxy. Распакуйте архив в новый каталог выпуска и следуйте `pwa/selfhost/README.md`. Не храните базу в каталоге исходников и не заменяйте её при обновлении. Запуск: `node pwa/selfhost/server.cjs` с настроенными `CLOUDCLI_DATA_DIR`, `PORT`, `TASKTIMER_PUBLIC_ORIGIN`.

В комплекте инструкция пользователя со скриншотами и примеры systemd. Проверьте `SHA256SUMS`; `REVISION` указывает точный исходный коммит. Пакет публикуется только после общих тестов PWA, серверных API/SQLite/browser проверок и настоящих HTTP/Service Worker проверок в GitHub Actions.

Этот выпуск не обновляет GitHub Pages, Android или desktop и сам не развёртывает приложение на вашем сервере.
