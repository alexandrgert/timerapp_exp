Серверный TaskTimer: тестовый экземпляр

Вернуться в приложение · Функции приложения со скриншотами

Раздел GitHub в общей инструкции относится к GitHub Pages. В этом экземпляре данные передаются только вашему серверу.

Подключение устройства

  1. Откройте адрес вашего сервера. В настройках найдите «Синхронизация со своим сервером».
  2. Введите отдельный ключ устройства, выданный администратором. GitHub-токен не нужен.
  3. Нажмите «Проверить подключение», затем «Синхронизировать». Перед первым обменом приложение сохраняет локальную копию.
  4. При желании отметьте «Запомнить ключ на этом устройстве». Ключ хранится в браузере, поэтому делайте это только на личном устройстве.
  5. Включите «Автоматическая синхронизация» отдельно на каждом устройстве: обмен через 10 секунд после изменения, каждые 30 секунд в видимом приложении и при возвращении.

Перенос с GitHub Pages

  1. На старых устройствах закончите обмен через GitHub и скачайте JSON-копию с каждого устройства.
  2. На новом сервере используйте пустую тестовую базу. На первом устройстве загрузите JSON-копию через настройки, затем выполните обмен.
  3. На остальных устройствах откройте новый адрес, введите свои ключи и выполните обмен. Повторно одну и ту же JSON-копию импортировать не нужно.
  4. Сверьте задачи, время, комментарии, удалённые записи и конфликты. Старую PWA и репозиторий пока сохраните.

JSON-импорт — перенос текущих данных, а не непрерывное продолжение истории GitHub-обмена. Не подключайте старую и новую базы к двум системам синхронизации одновременно. Для переноса причинной истории целиком администратор может применить документ v2 через условную запись API; ключи доступа в документ не входят.

Таймер и концентрация

Запуск, пауза и завершение задачи передаются всем подключённым устройствам после успешного обмена. Обычный таймер показывает прошедшее время, концентрация — оставшееся время в том же блоке текущей задачи. Итог дня расположен под заголовком «Мои задачи». Выбранная сортировка поддерживается автоматически; перетаскивание включает ручной порядок и не останавливает таймер.

Работа без сети и конфликты

Задачи остаются в локальном браузерном хранилище. При восстановлении сети обмен возобновляется. При конфликте откройте настройки: показаны название задачи, понятное имя поля и варианты значений. Для приоритетов видны различающиеся даты. Нерешённый конфликт сохраняется для выбора, но не мешает получать остановку таймера. В закрытой или свёрнутой PWA браузер может приостановить обмен.

Отключение устройства

«Забыть ключ» удаляет ключ из этого браузера. Это не отзывает доступ: для потерянного устройства администратор должен отозвать его ключ на сервере. Серверная авторизация защищает обмен, но уже загруженные задачи остаются на устройстве.
