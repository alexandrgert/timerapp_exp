# Завершённые записи внизу списка

Статус: подготовлено к публикации. Выпуск только для PWA.

После нажатия **«Завершить»** запись перемещается ниже незавершённых задач. Завершённые записи расположены по времени завершения: самая недавно завершённая — последняя. Для старой записи без времени завершения используется дата создания.

Работающая задача остаётся сверху. Ручной порядок остальных незавершённых задач сохраняется. Завершённые записи упорядочиваются автоматически, их перетаскивание недоступно. Во вкладке «В работе» они, как прежде, скрыты.

Приоритеты и история сессий не изменяются. Порядок сохраняется после перезапуска, так как определяется сохранённым временем завершения.

## Проверки и установка

Локально прошли 12 проверок модели и 3 браузерных сценария: ручной порядок, перетаскивание, завершение нескольких записей, перезагрузка и вкладка «Все».

После публикации нажмите **Обновить** в баннере приложения. Android и desktop этим выпуском не обновляются. Дальнейшая разработка ведётся в PWA, чтобы уменьшить зависимость от операционных систем устройств.
