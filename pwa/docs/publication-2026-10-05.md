# Публикация TaskTimer PWA — 2026-10-05

Постоянный адрес: [TaskTimer](https://alexandrgert.github.io/timerapp_exp/).

[GitHub Pages run 37284153548](https://github.com/alexandrgert/timerapp_exp/actions/runs/37284153548) завершился успешно. Опубликован commit `a025578489c3f97153f897d41c0fcf0229d2a471`, версия исходников `0.11.8`, одноразовая ветка `publish/approved-pwa-20261005-01`. Android/desktop в этом запуске не собирались. Рабочий workflow остаётся ручным; повтор или новая публикация требуют отдельного согласования.

## Проверено на опубликованном сайте

- Настоящие HTTPS-запросы страницы, manifest, Service Worker, модуля приложения, голосового worker и WASM вернули HTTP 200 с соответствующими MIME. SHA-256 опубликованного WASM совпал с закреплённым значением.
- Настоящий Chromium загрузил сайт без подмены сетевых маршрутов. Manifest использует `/timerapp_exp/` для `id`, `start_url` и `scope`; Service Worker управляет страницей в этом scope.
- Через интерфейс создана задача в изолированном браузерном профиле. После отключения сети и полной перезагрузки оболочка открылась, ID и название задачи сохранились в IndexedDB.
- В этом сценарии не обнаружены исключения страницы, ошибки консоли, HTTP-ошибки или неудачные онлайн-запросы. Локальный отчёт проверки: `/tmp/tasktimer-public-https-report.json` (временный файл, не опубликованный CI-артефакт).

## Границы проверки

Физические Android/iPhone, установка на главный экран, микрофон, качество диктовки и память телефона не проверялись. На опубликованном Pages-origin не выполнялись установка полной голосовой модели и распознавание. Проверка загрузки WASM и его SHA-256 сама по себе не доказывает работу голосового сценария.

Не проверены пользовательский WebDAV/CORS и обмен с реальными Android/desktop, а также принятие следующего обновления опубликованной оболочки. Сохранение задачи после офлайн-перезагрузки не заменяет эти проверки.

Ранее отдельная [PWA-проверка 2026-10-01](verification-2026-10-01.md) подтвердила реальную WASM-инференцию и Service Worker offline/update в GitHub Actions; это отдельное свидетельство на тестовом origin, а не проверка микрофона или обновления Pages.


## Первый выпуск PWA с функциями desktop

Отдельно разрешённая публикация: [GitHub Actions 37299198803](https://github.com/alexandrgert/timerapp_exp/actions/runs/37299198803), commit `5080feb81351444b3b5a8af120d78c04425b7946`. Постоянный адрес: https://alexandrgert.github.io/timerapp_exp/.

Добавлены план дня, режимы «Сегодня» / «В работе» / «Все», календарь истории, дневные приоритеты и массовое назначение, постоянный таймер, результат задачи и отчёты. Концентрация приостанавливает прежнюю задачу, создаёт отдельную запись и предлагает явное возвращение. Время относится ко дню начала сессии; при переходе суток запись закрывается в 23:59:59, а отсчёт концентрации продолжается до своего срока.

Перед публикацией прошли 52 небраузерных и 24 браузерных сценария, без ошибок и пропусков. После публикации выполнен отдельный ограниченный запуск Chromium по настоящему публичному HTTPS в чистом изолированном контексте, без route mocks:

- Service Worker содержит точный SHA публикации, контролирует страницу в scope `/timerapp_exp/`.
- Новый `desktop-domain.mjs` присутствует в настоящем CacheStorage этой ревизии.
- Через интерфейс созданы задача, приоритет, удаление/добавление в план.
- Концентрация приостановила задачу, создала собственную запись; остановка завершила её, явное продолжение вернуло прежнюю задачу.
- Открыты краткий и расширенный отчёты дня.
- Проверены экраны 1440 и 390 пикселей; горизонтального переполнения нет.
- После отключения сети выполнена полная перезагрузка: задачи, история концентрации и запущенный таймер сохранились.
- Ошибок страницы, консоли, сетевых запросов в онлайн-режиме и HTTP-ответов не обнаружено.

Скрипт, JSON-отчёт и снимки размещены в корневой папке проекта `documents/pwa-desktop-parity/publication/`. Данные проверки существовали только в временном браузерном профиле, который закрыт после проверки.

Ограничения: физический телефон, принятие этого обновления поверх прежней установленной PWA, микрофон, голосовая модель и WebDAV пользователя не проверялись этим запуском. Веб-публикация не меняет desktop и Android. Повторные публикации не запускались.
