# Сохранение текущего приоритета при удалении из плана

Статус: опубликовано 6 октября 2026 года. [Открыть PWA](https://alexandrgert.github.io/timerapp_exp/).

Если включено **«Сохранять приоритет при переносе на следующий день»**, действие **«Из плана»** теперь сохраняет приоритет выбранного дня. Например, задача с приоритетом 1 после удаления из плана остаётся с приоритетом 1 во вкладке «В работе».

Существующее добавление в план следующего календарного дня с сохранённым приоритетом остаётся. Если приоритет следующего дня уже задан отдельно, он не перезаписывается. При выключенной опции приоритет удаляемого дня, как прежде, сбрасывается до 4. Завершённые задачи не включают сохранение приоритета.

История сессий и работающий таймер не изменяются. Ранее сброшенные приоритеты автоматически не восстанавливаются.
