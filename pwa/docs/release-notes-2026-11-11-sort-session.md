# Сортировка без остановки таймера — 11 ноября 2026

Смена режима сортировки и перетаскивание изменяют только порядок записей. Они больше не запускают обработку просроченных напоминаний, концентрации и перехода суток, которая могла остановить работающую задачу. Исправлен также обмен уведомлениями о порядке между подключениями к хранилищу.

Текущая сессия сохраняет идентификатор, начало и открытое окончание. Штатная автоостановка по времени продолжает работать отдельно.

После установки обновления перезагрузите остальные открытые вкладки приложения, чтобы они получили новый код. Инструкция обновлена.

Выпуск относится только к PWA на GitHub Pages; отдельная серверная ветка, desktop и Android не менялись.
