# Автоостановка задачи без ответа в фоне

Пять минут на ответ теперь отсчитываются с планового момента напоминания, даже если приложение свёрнуто или открыта другая форма. Позднее открытие окна не запускает срок заново. Без ответа задача приостанавливается, а сессия заканчивается по истечении срока.

Если браузер приостановил выполнение или приложение закрыто, обработка произойдёт при возобновлении, но окончание сессии запишется по сохранённому сроку, без лишнего времени. Точный фоновый сигнал не гарантируется. Прежнее ограничение учёта суток сохраняется. Концентрация работает отдельно.

«Продолжить» начинает новый интервал напоминания. Старые ожидающие вопросы переходят на новое правило; если срок уже прошёл, задача может остановиться сразу после обновления. Восстановление JSON-копии начинает новый интервал, не переносит старую автоостановку.

Локально прошли 7 проверок напоминаний и 5 браузерных сценариев, включая скрытое окно, поздний показ, ответы из разных вкладок и офлайн-сохраняемое время окончания.

Для установки нажмите «Обновить» в баннере PWA. Android и desktop не обновляются. Дальнейшая разработка ведётся в PWA для уменьшения зависимости от операционных систем устройств.
