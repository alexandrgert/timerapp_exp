# Решения первой версии PWA

## Локальное состояние и время

Задачи, сессии и концентрация хранятся в IndexedDB. Чтение актуального состояния и изменение выполняются в одной `readwrite`-транзакции; BroadcastChannel и возврат фокуса обновляют другие вкладки. Редакторы передают только изменённые поля, сохраняя остальные значения и метаданные.

Таймер вычисляет длительность по сохранённым timestamps. Концентрация хранит дедлайн и после восстановления закрывает сессию именно по нему. Браузер может приостановить выполнение в фоне: точный сигнал при закрытом приложении не гарантируется. Данные остаются на устройстве; для переноса и защиты от очистки браузера предусмотрены JSON-копии.

## Отдельный клиент и будущая синхронизация

PWA — отдельный клиент в `timerapp/pwa`. Корневой `server.js` подключает переносимый `pwa/server.cjs`; сервер раздаёт статические файлы, пользовательские задачи на него не отправляются. Импорт принимает проверенную схему PWA, а не старые desktop/Android JSON.

Запись в legacy WebDAV не реализуется: общий ресурс со старыми клиентами небезопасен для новых метаданных. Следующий этап требует совместимого WebDAV v2 для PWA, Android и desktop: отдельного ресурса, causal revisions, tombstones, сохранения конфликтов и conditional PUT. До этого синхронизация между платформами отсутствует. Офлайн-диктовка также остаётся следующим этапом.

## Границы проверки

Итоговый автоматический прогон: 22 проверки прошли. Браузерные route-тесты с отключённым service worker и VM-тесты worker не подтверждают настоящий офлайн-запуск. Публичный HTTPS live URL, жизненный цикл service worker и установка/офлайн/восстановление на физических Android/iPhone ещё не проверены. Это первая версия, а не завершение всего плана. Сборки и выпуск требуют отдельного разрешения; сборки выполняются только в GitHub Actions.
