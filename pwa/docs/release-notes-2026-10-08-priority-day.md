# Приоритет задачи за выбранный день

Исправлено расхождение приоритета в редакторе и списке после переноса задачи между днями. Редактор теперь открывает дату и приоритет дня, выбранного в списке. Изменение приоритета сохраняется за этот день, не переписывая историю других дней.

Изменение только названия, описания или приоритета не меняет исходную дату задачи. Явно изменённая дата сохраняется вместе с выбранным в форме приоритетом. Сохранение учитывает конкурентные изменения после открытия формы.

Локально прошли 20 проверок модели и 2 браузерных сценария: редактирование перенесённой задачи, сохранность прошлого дня, перезагрузка и независимые изменения из двух вкладок.

Для установки нажмите «Обновить» в баннере PWA. Android и desktop не обновляются. Дальнейшая разработка ведётся в PWA для уменьшения зависимости от операционных систем устройств.

Статус: подготовлено к публикации.
