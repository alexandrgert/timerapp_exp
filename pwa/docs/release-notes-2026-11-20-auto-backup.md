# Автоматические резервные JSON-копии — 20 ноября 2026

В настройках резервного копирования можно включить создание JSON-копий и задать периодичность от 1 до 10080 минут. По умолчанию — каждый час. Каждая копия содержит дату и время в имени файла.

Выбор места хранения:

- На этом устройстве: загрузки браузера или выбранная папка, если браузер поддерживает доступ к файловой системе. Для автоматических загрузок может потребоваться разрешение браузера.
- На сервере GitHub: отдельные файлы в папке `backups` приватного репозитория из настроек синхронизации. Используются указанные репозиторий, ветка и токен с правом Contents: Read and write. После перезагрузки нужен введённый или сохранённый токен. Произвольный собственный сервер этим выпуском не подключается.

Файл синхронизации не перезаписывается. Архивы GitHub получают уникальный идентификатор, каждый создаёт отдельный коммит. Копии не удаляются автоматически. Токены и настройки автокопий в JSON не входят.

При закрытой PWA расписание не выполняется. В фоне браузер может задерживать сохранение. После перерыва создаётся одна актуальная копия. Ошибка записи не отмечается как успешное сохранение. Для восстановления используйте «Загрузить копию»; серверный JSON сначала скачайте из приватного репозитория.

Обновлены онлайн-инструкция и скриншот настроек. Продолжаем развивать PWA; Android, desktop и отдельный self-host этим выпуском не обновляются.
