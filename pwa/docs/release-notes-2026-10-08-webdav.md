# Уточнение настройки WebDAV

В PWA адрес сервера и путь к исходному файлу теперь можно вводить отдельно, как в desktop.

Для Билайна:
- сервер: `https://webdav.cloudbeeline.ru`;
- путь: `tasktimer/data.json`.

Перед обменом показывается итоговый адрес `https://webdav.cloudbeeline.ru/tasktimer/data.json.v2.json`. Прежний полный адрес исходного файла тоже поддерживается — оставьте отдельное поле пути пустым. Корень без файла, адрес веб-интерфейса облака и служебные файлы отклоняются до запроса.

Сообщение об ошибке объясняет предварительный OPTIONS и требования CORS. **Ограничение CORS на стороне Билайна этим выпуском не устраняется.** Успешная проверка desktop не подтверждает разрешение браузерного обмена. Формат данных и условная запись с ETag сохранены.

Локально прошли 22 проверки: транспорт и адреса, протокол и контроллер синхронизации, форма в Chromium. Реальный обмен с пользовательским облаком не проверялся.

Для установки нажмите «Обновить» в баннере PWA. Android и desktop не обновляются; дальнейшая разработка ведётся в PWA для уменьшения зависимости от операционных систем устройств.
