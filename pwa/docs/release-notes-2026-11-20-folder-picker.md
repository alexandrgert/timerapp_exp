# Выбор папки для резервных копий — 20 ноября 2026

Пока открыт системный выбор папки, автоматическое копирование ожидает его завершения. Защита действует при очередном сроке копии, возвращении фокуса, изменении видимости и завершении уже начатого экспорта. Повторное открытие выбора и сохранение настроек во время выбора временно блокируются. Отложенная копия не отмечается как сохранённая.

Если выбор отменён или браузер закрыл окно, прежнее место хранения остаётся выбранным. Вместо молчаливого отказа показывается сообщение с дальнейшими действиями.

Пользователь сообщил о закрытии окна без действий на Linux с Chrome 158.0.8127.36, как в отдельном окне PWA, так и во вкладке. Найденная в приложении конкурирующая автозагрузка воспроизведена и исправлена. Точная причина системного закрытия на устройстве пользователя не подтверждена.

В Chromium есть [отчёт об ошибке видимости окна при выборе папки](https://issues.chromium.org/issues/582407452). Исправление проверено в Chrome 158.0.8127.39; проверка в отчёте выполнена на Windows. Возможный временный обход — уменьшить системное окно выбора, чтобы оно не перекрывало браузер целиком. Для Chrome 158.0.8127.36 рекомендуется проверить доступные обновления. Это возможная причина, а не подтверждённый диагноз для Linux.

Инструкция обновлена. Выпуск меняет PWA для GitHub Pages; отдельная self-host версия, desktop и Android не обновляются.
