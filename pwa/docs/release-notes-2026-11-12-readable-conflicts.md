# TaskTimer PWA: понятные конфликты синхронизации

Вместо технического идентификатора, имени поля и JSON конфликт показывает название задачи, понятное описание поля и значения вариантов. При конфликте приоритетов по дням отображаются только различающиеся даты. Выбор сохраняет весь вариант, включая совпадающие дни, затем его можно передать другим устройствам синхронизацией.

Варианты нумеруются: номер не обозначает конкретное устройство. По журналу нельзя надёжно назвать вариант «этот телефон» или «другое устройство».

Название в шапке, заголовке окна, сигналах внимания и манифесте установки — TaskTimer PWA. Данные и идентификатор установленного приложения не меняются. Обновление отображаемого имени установленной PWA зависит от браузера.

Инструкция обновлена. Изменения относятся только к разрабатываемой GitHub PWA; отдельная серверная ветка, Android и desktop не меняются.
