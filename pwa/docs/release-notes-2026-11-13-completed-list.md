# Завершённые записи и ручной порядок — 13 ноября 2026

В ручном режиме новая запись вставляется после последней незавершённой видимой записи того же приоритета. Если такой записи нет — после записей более высокого приоритета. Порядок остальных записей сохраняется. Работающая задача по-прежнему сверху; «Добавить и начать» использует то же размещение.

Добавлен отдельный список «Завершённые» со счётчиком. «Дата создания» и «Дата завершения» фильтруют по конкретному локальному дню. Оба поля необязательны, при совместном заполнении применяются оба условия. Дата создания относится к фактическому созданию записи, а не дате плана. Поиск и фильтр приоритета продолжают работать. Список «Все» сохранён.

Инструкция дополнена пояснениями и актуальными скриншотами. Схема данных и протокол обмена не менялись. Порядок остаётся локальным для устройства.

Выпуск относится к GitHub PWA. Отдельная self-host ветка, Android и desktop не обновляются.
