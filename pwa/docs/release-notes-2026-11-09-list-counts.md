# Счётчики записей — 9 ноября 2026

Вкладки «Сегодня», «В работе» и «Все» показывают количество записей в скобках. На «Все» дополнительно отображаются открытые и завершённые записи. Числа учитывают поиск и фильтр приоритетов и обновляются после изменения, завершения или удаления задачи. Названия вкладок для средств доступности сохранены, счётчики доступны как дополнительное описание.

Инструкция дополнена пояснением в разделе3 и демонстрационным скриншотом. Локально прошли49браузерных сценариев без ошибок и пропусков; новый сценарий проверяет поиск, фильтрацию, статусы, завершение/удаление и узкий экран. Выпуск затрагивает только PWA на GitHub Pages; серверная, desktop и Android версии не обновляются.
