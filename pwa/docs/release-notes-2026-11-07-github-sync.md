# Ручной обмен через GitHub и описания в списке — подготовлено к выпуску

В настройках PWA WebDAV заменён ручной синхронизацией через GitHub Contents API. Используйте отдельный приватный репозиторий данных с README, существующую ветку и fine-grained token с Contents: Read and write только для этого репозитория. Проверка подключения не записывает данные; по умолчанию токен исчезает после закрытия/перезагрузки страницы. По желанию включите «Запомнить токен на этом устройстве» для автоматической подстановки; «Забыть токен» удаляет сохранённую копию и очищает поле. Токен не попадает в резервные копии или файл обмена. Имя репозитория и ветка запоминаются локально.

Перед первым обменом с каждым ресурсом сохраняется локальная восстановимая копия. Чтение файла data/state.v2.json и SHA выполняется одним ответом API. Существующие изменения объединяются причинным протоколом, удаления и конфликтующие значения сохраняются. Конкурентная запись запускает ограниченный повтор чтения и слияния; потеря ответа на запись не вызывает слепого повторения PUT. Максимальный размер JSON — 1 МБ. При ограничениях доступа, схемы или размера обмен останавливается с объяснением, локальные данные остаются. Порядок списка и настройки напоминаний остаются локальными. Автоматическая синхронизация не добавлялась.

Под названием задачи появилась строка описания. Если текст не помещается в одну строку или содержит переносы, кнопка «Далее» открывает полное описание. Пустые описания строку не занимают. Открытие описания не изменяет данные и не запускает таймер.

Инструкция и демонстрационные скриншоты обновлены. Android и desktop не менялись. Изменения не опубликованы. Проверки GitHub выполняются с моделируемым API и независимыми локальными хранилищами; реальный токен, приватный репозиторий пользователя, публичный хостинг и физический телефон требуют проверки после настройки и отдельно разрешённой публикации.

Локальная приёмка: общий прогон — 152 passed, 0 failed/skipped; итоговый целевой прогон после блокировки полей подключения на время запроса — 8 passed, включая отмену и просроченный токен. 10 VM-проверок Service Worker прошли; это не новая проверка настоящего публичного/offline Service Worker.

Публикация стала переносимой: base_path берётся из actions/configure-pages, поддерживается корень домена и другое имя репозитория, ссылки приложения/инструкции относительные. Добавлен pwa/docs/self-hosting.md с настройкой форка. Путь текущего экземпляра и namespace IndexedDB сохраняются.
