# Синхронизация таймера и больших файлов

Исправлен запуск с сохранённым конфликтом: подписи конфликтов инициализируются до первого отображения данных.

GitHub-обмен поддерживает файл до 20 МиБ. Для большой версии читаются метаданные, затем содержимое по неизменяемому SHA Git blob. Проверяются размер и UTF-8; запись использует SHA именно прочитанной версии. Ошибка чтения не приводит к перезаписи. История причинных изменений, удаления и конфликты сохраняются.

Нерешённые конфликты полей больше не запрещают обмен. Таймер получает запуск, паузу, продолжение и завершение с другого устройства вместе с идентификаторами и временем сессий. Автообмен проверяет сервер каждые 30 секунд в видимом открытом приложении, отправка изменений — через 10 секунд. В фоне, без сети или при закрытой PWA немедленная доставка не гарантируется; изменения применяются после успешного обмена. Одновременные независимые запуски по-прежнему требуют явного разрешения.

Инструкция обновлена. Установите обновление на всех устройствах; удалять файл обмена или задачи для устранения старого лимита не нужно. Рекомендуется сохранить JSON-копии на устройствах перед первым восстановленным обменом.

В этом выпуске публикуется GitHub PWA. Self-host дорабатывается отдельно; Android и desktop не меняются.
