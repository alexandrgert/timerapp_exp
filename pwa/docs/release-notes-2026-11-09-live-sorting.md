# Постоянная сортировка по приоритету

Выбор «Приоритет 1 → 4» или «Приоритет 4 → 1» включает постоянный режим. Новые задачи, изменение приоритета и входящие изменения автоматически перестраивают список. Режим сохраняется на устройстве после перезагрузки и переключения вкладок. При равных приоритетах сохраняется выстроенный порядок.

Перетаскивание сначала фиксирует актуальный порядок и применяет перемещение в одной транзакции, затем включает «Вручную». Переключение на ручной режим также сохраняет текущий порядок. Работающая задача закреплена сверху; завершённые остаются внизу по хронологии. Инструкция обновлена. Выпуск только для PWA GitHub Pages.
