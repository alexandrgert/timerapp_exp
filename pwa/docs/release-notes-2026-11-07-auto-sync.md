# Автоматическая синхронизация GitHub

Добавлен добровольный переключатель автоматического режима на каждом устройстве и для выбранного репозитория/ветки. При доступном токене обмен выполняется на открытии, возвращении в видимое приложение, восстановлении сети, через 10 секунд после последней сохранённой правки и раз в 2 минуты в видимой странице. Тики таймера и локальный порядок списка не вызывают отправку. Неизменённый файл не перезаписывается: периодические проверки не создают коммиты.

Ручной и автоматический обмены используют общий Web Lock между вкладками одного экземпляра. При отсутствии Web Locks остаётся ручной режим с защитой SHA. Новые локальные изменения во время отправки сохраняются и планируют следующий обмен. Сетевая ошибка вызывает повтор с увеличивающейся паузой, ограничения GitHub учитываются; каждая попытка сначала читает сервер. Ошибка токена или конфликт требуют действия пользователя, предупреждение доступно в верхней панели и настройках. Отключение режима отменяет текущий автоматический запрос. Ручная кнопка сохранена.

В свёрнутой/закрытой PWA выполнение не гарантируется браузером. Данные сохраняются локально, при возвращении обмен возобновляется. Настройки автоматического режима и токен не входят в задачи и экспорт. Инструкция и скриншот обновлены. Проверки обмена используют моделируемый API; работа с настоящим пользовательским токеном проверяется пользователем на его устройствах.
