# PWA: предупреждение при закрытии
Пользователь: «при закрытии приложение должно быть предупреждение, как в декстопе было».
Уточнение: «только в перечисленных случаях. сворачивание не надо».
Утверждены: работающий таймер задачи/концентрации, несохранённый редактор, запись голоса.
R1 beforeunload только при риске, стандартный браузерный текст/ограничения; no tray.
R2 clean/saved/reverted/closed editor не вызывает предупреждение.
R3 голос не теряется без предупреждения при записи/распознавании/неперенесённом тексте.
R4 явное принятое обновление не создаёт повторный prompt; сбой/отмена не выключают защиту.
R5 scope PWA only, pwa/development; no release/build/push approval.
Plan: one implementation agent, independent review, local tests. No new dependencies.
