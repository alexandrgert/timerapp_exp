# Измерение размера Android Preview

Сборку и тесты запускаем **только в GitHub Actions после отдельного явного подтверждения пользователя**. Workflow `Android preview` имеет только `workflow_dispatch`; push не запускает его. Локальная сборка запрещена.

После подтверждения запустить workflow для согласованного commit ветки `android/session-editor`. APK и отчёт публикуются как артефакт только после успешных unit- и UI-тестов. Название `tasktimer-preview-<bytes>-bytes` содержит точный размер APK, не размер ZIP артефакта.

Внутри артефакта:

- `app-debug.apk` — `com.timerapp.exp.preview`, debug, с движком sherpa-onnx, без языковой модели.
- `size-and-sha256.md` — размер, SHA-256, изменения относительно исходной базы и предыдущего APK с Vosk; также доступен в GitHub Summary.
- `size-comparison.json` — те же измерения и идентификатор commit для воспроизводимого сравнения.

База: **59 820 732 байта**, commit `b90dbdd`, [успешный запуск 36236814073](https://github.com/alexandrgert/timerapp_exp/actions/runs/36236814073), debug APK до голосового ввода. Изменение в байтах = новый размер − база; процент = изменение / база × 100, округлён до двух знаков. Разница включает все изменения после базы, в том числе концентрацию; это не отдельное измерение размера движка распознавания.

Дополнительная база для замены движка: **101 063 213 байт**, commit `65cc580`, [успешный запуск с Vosk 36238546667](https://github.com/alexandrgert/timerapp_exp/actions/runs/36238546667). В отчёте отдельно вычисляются изменение относительно этого APK и процент от его размера. Сравнение включает все изменения после версии с Vosk и не выдаётся за изолированное измерение движка.

Сравнивать одинаковые build type, ABI и параметры упаковки. При изменении этих настроек понадобится новая согласованная база. SHA-256 позволяет проверить, что установлен именно измеренный APK.

Модель `sherpa-onnx-zipformer-ru-int8-2025-04-20` учитывается отдельно: скачивание **60 239 942 байта**, полное распакованное содержимое архива **74 004 174 байта**, устанавливается целиком, плюс маркер установки 64 байта и накладные расходов файловой системы. Источник и контрольная сумма зафиксированы в [offline-voice.md](offline-voice.md). Эти размеры проверены для модели; они не означают, что измерен новый APK с sherpa-onnx. Архив после установки удаляется.

Размер APK не равен месту установленного приложения: Android дополнительно размещает нативные библиотеки, оптимизированный код, данные и кэш. Итоговое место с установленной моделью нужно отдельно измерить на устройстве после разрешённой GitHub-сборки. APK с Vosk уже измерен; новая сборка с sherpa-onnx и её замер ещё не выполнялись.
