# Измерение размера Android Preview

Сборку и тесты запускаем **только в GitHub Actions после отдельного явного подтверждения пользователя**. Workflow `Android preview` имеет только `workflow_dispatch`; push не запускает его. Локальная сборка запрещена.

После подтверждения запустить workflow для согласованного commit ветки `android/session-editor`. APK и отчёт публикуются как артефакт только после успешных unit- и UI-тестов. Название `tasktimer-preview-<bytes>-bytes` содержит точный размер APK, не размер ZIP артефакта.

Внутри артефакта:

- `app-debug.apk` — `com.timerapp.exp.preview`, debug, с движком Vosk/JNA, без языковой модели.
- `size-and-sha256.md` — размер, SHA-256, изменение относительно базы; также доступен в GitHub Summary.
- `size-comparison.json` — те же измерения и идентификатор commit для воспроизводимого сравнения.

База: **59 820 732 байта**, commit `b90dbdd`, [успешный запуск 36236814073](https://github.com/alexandrgert/timerapp_exp/actions/runs/36236814073), debug APK до голосового ввода. Изменение в байтах = новый размер − база; процент = изменение / база × 100, округлён до двух знаков. Разница включает все изменения после базы, в том числе концентрацию; это не отдельное измерение размера Vosk.

Сравнивать одинаковые build type, ABI и параметры упаковки. При изменении этих настроек понадобится новая согласованная база. SHA-256 позволяет проверить, что установлен именно измеренный APK.

Модель `vosk-model-small-ru-0.22` учитывается отдельно: скачивание **46 236 750 байт**, распакованное содержимое **91 289 240 байт**, маркер 64 байта плюс накладные расходы файловой системы. Источник и контрольная сумма зафиксированы в [offline-voice.md](offline-voice.md). Эти размеры уже проверены для модели; они не означают, что измерен новый APK. Архив после установки удаляется.

Размер APK не равен месту установленного приложения: Android дополнительно размещает нативные библиотеки, оптимизированный код, данные и кэш. Итоговое место с установленной моделью нужно отдельно измерить на устройстве после разрешённой GitHub-сборки. На этом этапе новая сборка и измерение APK ещё не выполнялись.
