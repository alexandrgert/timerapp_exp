# Офлайн-диктовка Android

Кнопка «Новая задача» открывает название и описание с микрофонами. В редактировании задачи микрофон доступен у описания, а в форме любой сессии — у комментария. «Добавить текст» дописывает распознанный результат к существующему полю, не сохраняет задачу или сессию автоматически. Отмена/Back не меняет исходное поле. Распознанный текст можно исправить перед добавлением.

## Zipformer вместо Vosk

По выбору пользователя Vosk/JNA заменены на sherpa-onnx и русскую offline-transducer модель `sherpa-onnx-zipformer-ru-int8-2025-04-20`. Encoder и joiner INT8, decoder FP32 — это официальный состав INT8-пакета. CPU, два потока, greedy search; `OfflineRecognizer` получает абсолютные пути к четырём файлам в приватном каталоге приложения. Ни аудио, ни текст не отправляются в сеть.

Zipformer работает с завершёнными записями: микрофон записывает **до 60 секунд**, затем выключается и начинается распознавание. Можно остановить раньше кнопкой. Во время обработки интерфейс показывает «Распознаю… Микрофон выключен»; текст появляется после обработки целой записи. «Продолжить диктовку» добавляет следующий фрагмент. Ограничение предотвращает неограниченный рост памяти; запись не режется на перекрывающиеся куски и не теряется во время параллельного декодирования. PCM16 mono 16 кГц хранится только в RAM (до 1,92 МБ PCM + 3,84 МБ нормализованных samples; память модели и нативного inference считается отдельно). Автоматическая остановка на 60-й секунде — явная граница записи; лучше закончить фразу и нажать «Остановить» раньше.

Начало записи требует RECORD_AUDIO. Сворачивание приложения останавливает микрофон и обрабатывает текущую запись; закрытие диалога отменяет операцию. Нативные загрузка модели и decode не прерываются мгновенно: отменённый результат не применяется, ресурсы освобождаются после возврата JNI. Общая отменяемая блокировка удерживается до освобождения нативных ресурсов: повторно открытый диалог ждёт завершения предыдущей операции и не загружает вторую модель одновременно. Состояние ошибки не стирает ранее распознанный текст. Пустой результат, отказ микрофона/разрешения, нехватка памяти сообщаются пользователю; ручной ввод доступен.

## Отдельная загрузка модели

Первое открытие предлагает скачать модель по кнопке. Единственный сетевой запрос — GET официального публичного архива (HTTPS redirect GitHub → release-assets; переход на HTTP запрещён). После установки распознавание работает без сети, в том числе в авиарежиме.

Модель и временные файлы находятся в `Context.filesDir/voice-model`, отдельно от данных задач и APK. Загрузка показывает прогресс, поддерживает отмену/повтор. Проверяются точные размер и SHA-256 до распаковки. TAR.BZ2 читается Apache Commons Compress 1.27.1 с ограничениями фактически извлечённых байтов, числа записей и путей; ссылки, sparse и специальные файлы запрещены. Готовая директория устанавливается атомарно после проверки обязательных файлов. Отмена/ошибка удаляет частично распакованные файлы и незавершённую загрузку. Полностью загруженный архив с проверенным SHA-256 сохраняется в одном версионном файле для повторной установки без сети; перед каждым повтором размер и SHA-256 проверяются заново. Повреждённый архив удаляется, после успешной установки архив удаляется. Предыдущая папка Vosk удаляется **только после** успешной установки Zipformer; до этого остаётся на диске, но новым движком не используется. Данные задач не меняются.

Официальный архив проверен 2026-09-26:

- TAR.BZ2: **60 239 942 байта** (60,24 МБ).
- Все распакованные файлы: **74 004 174 байта** (74,00 МБ), включая README с источником модели, bpe.model и два официальных тестовых WAV. Записи пользователя на диск не сохраняются.
- SHA-256: `d6a651569aacc9a177259fa54705dd76acae23f6a4d62ea6797bd220d4b57163`.
- Маркер `.ready`: 64 байта. Архив после установки удаляется.
- Проверка свободного места: архив + распаковка + 16 МиБ = **151 021 332 байта**; интерфейс просит 152 МБ дополнительно к уже занятому месту старой моделью.

В APK модель не входит. Зависимость движка — официальный `sherpa-onnx-static-link-onnxruntime-1.13.8.aar`, **38 691 998 байт**, SHA-256 `b22c3fc1b6a45666d28892bb2f7694beeb77a8362d7ebd77c1a5431ec9435471`. Gradle загружает и проверяет его при разрешённой сборке; бинарник не коммитится, конфигурация проекта сама по себе не запускает загрузку. AAR содержит arm64-v8a, armeabi-v7a, x86 и x86_64. Размер AAR не равен изменению APK. Последний APK с Vosk: **101 063 213 байт**, база до голоса: **59 820 732 байта**; новый APK ещё не собран.

## Проверки

Подготовлены unit-тесты дописывания текста, точности/лимитов PCM-буфера, TAR slip, ссылок, размеров, количества записей и отмены. Проверки UI отмены/форм остаются. После миграции тесты **не запускались**, сборки не было: требуется отдельное разрешение пользователя на каждый GitHub запуск. Локальные APK запрещены.

На телефоне проверить качество одних и тех же русских фраз относительно Vosk, задержку/память, продолжение диктовки, остановку на 60 секундах, авиарежим, занятый микрофон/отзыв разрешения, Back/сворачивание/поворот во время записи и decode, отмену/повтор скачивания, нехватку места и обновление со старой моделью. ELF-сегменты официального AAR проверены на 16-КБ alignment; совместимость готовой APK и работа на таком устройстве пока не проверены. Улучшение качества до реального сравнения не гарантируется.

## Исправление распаковки после проверки на телефоне

После отчёта о зависании/обрыве найдено отсутствие буфера между FileInputStream и BZip2CompressorInputStream: BitInputStream из Commons Compress читает сжатый поток побайтно. Теперь используется 64-КиБ буфер **до** декомпрессора. Это устраняет миллионы мелких обращений к файловому потоку; точное исключение на телефоне без журнала неизвестно, поэтому причина обрыва пока не доказана.

Прогресс распаковки показывает реально записанные байты из 74,0 МБ. Полный проверенный архив сохраняется при отмене/ошибке распаковки, кнопка предлагает повторить установку. Не хватает места — учитывается уже сохранённый архив. Ошибки установки, включая нехватку RAM и LinkageError компонента распаковки, показываются как ошибки установки; запрос разрешения микрофона для них не предлагается.

Подготовлены четыре регрессионных unit-теста: пакетное чтение сжатого потока и прогресс, повтор распаковки после отмены, отбрасывание повреждённого кэша, сообщения ошибок. Добавлен Android instrumentation smoke-тест распаковки маленького независимого TAR.BZ2 fixture на файловую систему устройства: он проверяет библиотеку на Android без скачивания модели. Новые тесты **не запускались**, новой сборки нет. На физическом телефоне по-прежнему нужна проверка полной модели после отдельно согласованной сборки.
