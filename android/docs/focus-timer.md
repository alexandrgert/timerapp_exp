# Концентрация в Android

Кнопка «Концентрация» видна у незавершённой задачи. Диалог принимает 1–180 минут и запрашивает приоритет, если он ещё не назначен. Активный отсчёт над списком остаётся виден при фильтрации задач; второй таймер не запускается до остановки первого.

Старт ставит другую текущую задачу на паузу и открывает сессию выбранной задачи (либо использует уже открытую). Остановка и истечение срока ставят выбранную задачу на паузу; предыдущая задача автоматически не возобновляется. Обычная остановка, завершение, удаление задачи или её активной сессии отменяют концентрацию. Продолжительность открытой сессии включает время работы до включения концентрации, если сессия уже шла.

Используются существующие поля `focus_timer` без изменения схемы данных. Desktop создаёт отдельную служебную задачу концентрации; Android использует выбранную пользователем задачу. На desktop ничего не менялось. Старый WebDAV merge сохраняет прежние ограничения; это не распределённый таймер с защитой от конфликтов между устройствами.

Отсчёт восстановится по `ends_at` после перезапуска процесса. При следующем чтении/изменении данных просроченная сессия закрывается ровно в `ends_at`, поэтому время в фоне не прибавляется сверх срока. `AlarmManager.setAndAllowWhileIdle` сообщает об окончании даже без открытого экрана. Receiver только читает сохранённые данные и отправляет уведомление: он не создаёт дополнительного конкурирующего писателя `data.json`.

Android может задержать неточное фоновое уведомление в режиме энергосбережения. При запрете уведомлений отсчёт работает, но уведомления не будет. После принудительной остановки приложения или перезагрузки телефона напоминание восстановится только при открытии приложения. Экран предупреждает о задержке и выключенных уведомлениях. Специальное разрешение точных будильников не запрашивается.

Проверки: `FocusTimerTest` покрывает переключение задач, повторное использование открытой сессии, восстановление и закрытие по сроку, раннюю остановку, отмену при удалении/паузе, сериализацию, запрет второго таймера и недопустимую длительность. Написаны, но НЕ запускались: любые сборки/компиляция ожидают отдельного разрешения пользователя. APK — только GitHub Actions.
