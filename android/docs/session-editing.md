# Ручные сессии Android

История задачи → «Добавить сессию» открывает форму без записи данных. Начальные значения — последний час до текущего момента. Дата вводится в формате ГГГГ-ММ-ДД, время — ЧЧ:ММ с необязательными секундами и долями секунд; доступны системные пикеры. Разные дни разрешены. Окончание должно быть позже начала.

«Редактировать» в строке истории меняет начало, окончание и комментарий. У активной сессии переключатель «Сессия продолжается» сохраняет открытый конец; его отключение позволяет закончить сессию указанным временем. Закрытая сессия не превращается в работающую. Правка только комментария сохраняет исходные строки timestamps (offset, секунды, наносекунды), ID и bitrix_record_id. Завершённая задача остаётся завершённой.

Удаление задачи и отдельной сессии требует подтверждения. Отмена и Back до сохранения не пишут данные. Во время записи закрытие диалога и повторные действия временно отключены; ошибка остаётся в диалоге с введёнными значениями для повторной попытки.

Изменения переданного времени локальные: запись Битрикс24 не корректируется и повторно не отправляется. Существующий merge не изменён: синхронизация может вернуть старую длительность, непустой комментарий или удалённый объект. Предупреждение появляется в релевантной форме при включённой либо настроенной WebDAV-синхронизации. Согласованное устранение этого ограничения требует отдельного изменения общего контракта.

## Проверка в GitHub Actions

Unit: TaskRepositoryTest (создание/правка/удаление, статусы, отсутствующие ID, точность, Б24, save/load), SessionInputTest (строгий календарь, DST, сохранение точности). Compose: SessionDialogsTest (открытие без записи, отмена, неверный диапазон, произвольный интервал через полночь, ошибка записи и повтор, подтверждение удаления). Локальные Gradle/APK не запускались.

На проверочной APK отдельно проверить системные пикеры, Back, клавиатуру на небольшом экране, переход из списка задач в историю и обратно, работающий таймер, подтверждение удаления задачи с её названием. Для голоса, офлайн-модели и концентрации изменений в этом этапе нет.
